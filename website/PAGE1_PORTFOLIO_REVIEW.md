## Visual direction
- Blue = primary analytical information.
- Teal = healthy/positive state.
- Rose = risk/negative signal.
- Navy = structural/brand layer.
- White/light gray = long-form reading surface.

## Before merging
- Review the dashboard at desktop width >= 1440px.
- Verify charts still resize after the dashboard is placed inside the portfolio frame.
- Verify all anchors and sticky case-study navigation.
- Verify the GitHub Pages setting is enabled in repository Settings -> Pages -> Source: GitHub Actions.
